# Salon Registration App

A Vue front-end for the BlurEngine game database based on an ASP.NET REST API.

## Tech Stack

- TypeScript
- Vue & Vue Router
- Vite
- Docker
- GitHub Actions CI/CD
- Bootstrap

## Code Style

- Use TypeScript
- Follow ESLint configuration
- Use 2 spaces for indentation
- Interface names must begin with capital 'I'
- Enum names must begin with capital 'E'
- Type names PascalCase
- Function and variable names camelCase

## Code Rules

- No TypeScript enums
- Do not edit configuration files

## Architecture

- Compose views from small components

## Security

- JWT & refresh tokens
- Validate all user inputs
